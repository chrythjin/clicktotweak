### 📌 "윈도우 새로 깔고 나면 제일 먼저 챙겨 깔던 프로그램, 기억하시나요?"

2000년대 중후반, PC를 좀 만질 줄 안다면 누구나 바탕화면에 두고 쓰던 필수 유틸리티 **'클릭투트윅(Click To Tweak)'**.

하지만 원작자의 개발 중단 이후 10여 년이 흐르면서, 현대의 64비트 Windows 10/11 환경에서는 호환성 문제와 구형 드라이버로 인해 정상적으로 실행하기 어려웠습니다.

**Click To Tweak Modern**은 그 시절 클릭투트윅의 편리함과 직관적인 감성을 그대로 살려 최신 기술로 완전히 새로 빚어낸 오픈소스 프로젝트입니다.

과거 12개로 나뉘어 있던 분산 실행 파일들을 **Rust 2024 + Tauri v2** 기반의 **약 6MB 단일 포터블 바이너리**로 깔끔하게 통합했습니다. 복잡한 인스톨러 없이, 파일 하나만 실행하면 윈도우의 가려운 곳을 시원하게 해결할 수 있습니다.

## ✨ 왜 클릭투트윅 모던인가요?

* 🪶 **단 하나의 포터블 파일 (Zero-Install, ~6MB)**  
  인스톨러도, 백그라운드에 몰래 상주하는 서비스도 없습니다. 어디서나 USB에 넣어 다니며 가볍게 실행하고, 원할 때 닫으면 시스템에 찌꺼기를 남기지 않습니다.

* 🛡️ **커널 드라이버 없이 동작하는 설계**  
  과거 구버전에서 치명적인 시스템 크래시를 유발하던 낡은 32비트 커널 드라이버(`.sys`)를 사용하지 않습니다. Windows 공식 Win32 사용자 모드 API만으로 동작하므로 커널 수준 충돌 요인이 없지만, 레지스트리와 파일을 직접 변경하는 작업이므로 잘못된 설정은 시스템에 영향을 줄 수 있습니다.

* 🪟 **Windows 11의 답답한 부분을 긁어주는 맞춤 트윅**  
  매번 번거롭게 한 번 더 눌러야 했던 '더 많은 옵션 표시'를 없애고 **클래식 우클릭 메뉴를 복원**합니다. 바탕화면에 `내 PC`, `휴지통` 아이콘을 즉시 꺼내고, 시작 메뉴의 귀찮은 Bing 웹 검색 결과를 끄는 등 일상에서 바로 체감되는 편의성을 제공합니다.

* 🎨 **세련되고 눈이 편안한 Fluent 다크 UI**  
  20년 전 투박했던 회색 창 대신, 윈도우 11의 디자인 언어와 자연스럽게 어우러지는 현대적인 다크 테마 카드형 인터페이스를 적용했습니다.

## 🛠️ 주요 기능 둘러보기

### 1. 🚀 Windows 11 & 시스템 트윅
매일 마주치는 윈도우의 사소한 불편함들을 클릭 한 번으로 해결합니다.
* **Windows 11 클래식 우클릭 복원**: 답답한 2단계 우클릭 메뉴를 없애고 친숙한 클래식 메뉴를 바로 띄웁니다.
* **바탕화면 시스템 아이콘 제어**: 기본으로 숨겨져 있는 `내 PC`, `휴지통`, `제어판`, `사용자 문서`, `네트워크` 아이콘을 원클릭으로 켜고 끕니다.
* **로컬 전용 검색**: 시작 메뉴에서 느리고 번거로운 Bing 웹 검색 결과를 차단하고, 내 PC 속 앱과 파일만 빛의 속도로 찾습니다.
* **마우스 & 키보드 반응 속도**: 게이머들의 필수 설정인 '마우스 포인터 정확도 향상(가속도)'을 1:1 센서 매핑으로 해제하고 키보드 반복 지연을 단축합니다.
* **SSD 용량 대량 확보**: 쓰지도 않는데 용량만 차지하는 최대 절전 모드 파일(`hiberfil.sys`)을 비활성화하여 C 드라이브 수십 GB를 즉시 돌려받습니다.
* **비밀 제어판(GodMode) 및 핵심 도구 런처**: 윈도우의 200여 가지 세부 설정이 총망라된 '갓모드'와 핵심 제어판 애플릿 12종을 바로 엽니다.

### 2. 🧹 스마트 정크 & 레지스트리 청소
디스크 공간을 갉아먹는 임시 파일과 불필요한 찌꺼기 레지스트리를 안전하게 정리합니다.
* **정크 & 브라우저 캐시 청소**: 시스템 `%TEMP%`, Windows 임시 파일, 크래시 덤프, 웹 브라우저(Edge, Chrome, Whale) 캐시를 깔끔하게 비웁니다.
* **고아 레지스트리 정리 (Registry Cleaner)**: 프로그램을 지워도 남아 있는 빈 껍데기 실행 경로(`App Paths`)와 유효하지 않은 공유 라이브러리(`Shared DLLs`) 참조를 선별 정리합니다.
* **파일 파쇄기 (File Shredder)**: 1~7회 덮어쓰기 후 삭제합니다. 저장장치 매핑, 파일 시스템, 스냅샷 및 백업에 따라 원본 데이터가 남을 수 있어 복구 불가나 특정 보안 규격 준수를 보장하지 않습니다.

### 3. 🪟 창 & 프로세스 제어 (추억의 trans / pollock 기능)
작업 표시줄과 화면 위의 창들을 마우스로 자유자재로 다룹니다.
* **크로스헤어(스포이트) 피커**: 타깃 아이콘을 원하는 창 위에 끌어다 놓기만 하면 즉시 대상을 선택합니다.
* **실시간 창 투명도 조절**: 10%부터 100%까지 슬라이더로 부드럽게 투명도를 바꿀 수 있습니다.
* **창 항상 위에 고정 (Always-on-Top)**: 다른 작업을 하면서 참고해야 할 메모장이나 동영상 창을 화면 맨 위에 고정합니다.
* **프로세스 제어 & 메모리 다이어트**: 응답 없음 상태에 빠진 프로그램을 강제 종료하지 않고 잠시 멈추거나(`NtSuspendProcess`), 원클릭으로 메모리 사용량을 줄입니다.
* **특수 폴더 실제 이관**: 다운로드·바탕화면·문서 폴더의 저장 위치를 D 드라이브 등으로 바꿀 때 기존 파일과 하위 폴더 항목까지 새 경로로 실제 이동합니다. 같은 이름이 있으면 번호를 붙여 함께 보존합니다.

### 4. ⏰ 컴퓨터 자동 예약 종료
* "유튜브 영상 보다가 잠들어도 안심!"
* 복잡한 윈도우 명령어(`shutdown -s -t ...`)를 외울 필요 없이, 슬라이더나 시간 입력 한 번으로 원하는 시간에 시스템 종료, 재부팅, 최대 절전을 예약하고 언제든 1클릭으로 취소할 수 있습니다.

### 5. 🚦 안전한 시작프로그램 & 네트워크 도구
* **시작프로그램 안전 관리**: 64비트/32비트 `Run` 키, 작업 관리자의 StartupApproved 비활성화 상태, 시작 폴더 항목을 함께 보여줍니다. 항목을 끄면 원본 값을 `ClickToTweakModern\DisabledStartup` 격리 키로 옮겨 보관하므로 언제든 되돌릴 수 있습니다.
* **실시간 트래픽 모니터**: 현재 송수신되는 네트워크 대역폭(KB/s, MB/s)을 실시간으로 확인합니다.
* **시스템 전역 광고 차단 & DNS 플러시**: `hosts` 루프백 필터링을 통해 브라우저와 앱의 광고 요청을 가볍게 차단하고, 꼬인 DNS 캐시를 즉시 비웁니다. hosts 파일을 덮어쓰기 전에 원본을 같은 폴더에 백업하고, 교체는 원자적(rename) 방식으로 처리해 중간 실패 시 DNS가 끊기지 않도록 했습니다. (관리자 권한 필요)

### 6. 🛡️ 파일 보호 & 백업 가드
* 보호 대상으로 등록한 **개별 파일**의 현재 상태를 스냅샷으로 보관하고, 언제든 1클릭으로 그 시점의 파일로 되돌립니다.
* 스냅샷과 복원 이력이 화면에 남기 때문에 "어떤 파일이 언제 바뀌었는지" 확인하고 비교할 수 있습니다.
* 복원할 때는 등록된 보호 대상 경로로만, 저장소 안의 스냅샷 파일로만 복원되도록 경로를 검증합니다.

### 7. 🛡️ 안심 복원 센터
* 시스템 설정을 변경하기 전 이전 레지스트리 상태를 백업 스냅샷으로 보관합니다.
* 설정 후 마음에 들지 않거나 이상이 발생하면 언제든 1클릭으로 이전 상태로 안전하게 되돌릴 수 있습니다.
* 되돌리기가 일부 실패하면 실패 항목을 그대로 알려 "완전히 복원된 것처럼 보이지만 실제로는 안 된" 상황을 막습니다.

### 8. 🔑 관리자 권한 실행
* 기본 실행은 일반 사용자 권한이라 UAC 창이 뜨지 않습니다.
* HKLM 레지스트리, `hosts` 광고 차단, `C:\Windows\Temp` 정리처럼 관리자 권한이 필요한 기능은 상단 **"관리자 권한 필요"** 버튼으로 UAC 승인을 거쳐 다시 실행할 수 있습니다.

## 🔄 시대에 맞춰 덜어낸 것들 (Modernized for Windows 11)

*"옛날 클릭투트윅에 있던 그 기능들은 왜 안 보이나요?"*

세월이 흐르며 윈도우 운영체제와 하드웨어도 비약적으로 발전했습니다. 오늘날의 PC 환경에서는 오히려 성능을 떨어뜨리거나 의미가 없어진 구시대 유물들은 과감하게 제외했습니다.

| 제외된 구시대 기능 | 제외 사유 |
| :--- | :--- |
| **MTU / TCP 수신 윈도우(RWIN) 패치** | 과거 ADSL/전화선 시절의 트윅으로, 현대 Windows 11의 CTCP 엔진 및 기가비트 인터넷 환경에서는 오히려 다운로드 속도를 급감시킵니다. |
| **IE 전용 광고 차단 BHO (`WebInterception.dll`)** | Internet Explorer가 공식 은퇴함에 따라, 시스템 전역 `hosts` 루프백 필터링 방식으로 전환했습니다. |
| **CD/DVD 자동 실행(Autorun) 방지** | ODD를 거의 사용하지 않는 현대 PC 환경에 맞춰 불필요한 레지스트리 수정을 줄였습니다. |
| **구형 32비트 커널 드라이버 (`SMFDDrv`, `FProtMod`)** | 64비트 Windows 보안 규격(DSE / PatchGuard)과 충돌해 시스템 크래시를 유발할 수 있어, 커널 대신 사용자 모드 스냅샷 방식으로 대체했습니다. |

## 💻 직접 빌드하기 (Build from Source)

소스코드를 내려받아 직접 빌드해보고 싶으신 개발자분들은 아래 순서를 따라주세요.

### 준비물
* [Rust](https://www.rust-lang.org/) (1.85 버전 이상 권장)
* [Node.js](https://nodejs.org/) (v20 이상 또는 v22 권장)
* Visual Studio C++ x64 Build Tools

```powershell
# 1. 저장소 복제하기
git clone https://github.com/chrythjin/clicktotweak.git
cd clicktotweak

# 2. 프론트엔드 패키지 설치 및 빌드
npm install
npm run build

# 3. Rust 네이티브 바이너리 빌드 (릴리스 모드)
cargo build --release --manifest-path src-tauri/Cargo.toml

# 🎉 빌드 완료!
# src-tauri/target/release/clicktotweak.exe 바이너리가 생성됩니다.
```
