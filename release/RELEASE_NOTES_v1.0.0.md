# Click To Tweak Modern v1.0.0 🚀

10년 전 개발이 중단되었던 국민 PC 최적화 유틸리티 **'클릭투트윅(Click To Tweak)'**을 현대 Windows 10/11 x64 환경에 맞춰 완전하게 재창조한 공식 v1.0.0 릴리스입니다.

---

### 📦 손쉬운 실행 방법 (Zero-Install 무설치 포터블)
1. 아래 Assets에서 **`ClickToTweak-v1.0.0-Portable.zip`** 파일을 다운로드합니다.
2. 원하는 위치(바탕화면, USB 드라이브 등)에 압축을 풉니다.
3. **`ClickToTweak.exe`** 또는 **`실행하기.bat`**을 더블 클릭하여 즉시 실행합니다!

---

### ⚡ 주요 변경 및 혁신 사항

1. **커널 드라이버 배제**:
   - 구버전에서 치명적 시스템 충돌(`CRITICAL_STRUCTURE_CORRUPTION`)을 일으키던 32비트 무서명 커널 드라이버(`SMFDDrv`, `FProtMod`)를 사용하지 않고 유저모드 API로 재설계했습니다.
2. **단일 네이티브 바이너리 통합**:
   - 과거 12개의 분산 실행 파일(`CTTUtil`, `DesktopFixer`, `trans`, `pollock`, `MemRes` 등)을 단 약 5MB 크기의 경량 단일 Rust 바이너리로 통합했습니다.
3. **제어판 & 시스템 도구 센터 신설**:
   - 바탕화면 시스템 아이콘 꺼내기 (내 PC, 휴지통, 제어판, 문서, 네트워크)
   - 마우스 포인터 정확도 향상(가속도) 1:1 매핑 해제 및 키보드 반응 속도 극대화
   - 최대 절전 모드(`hiberfil.sys`) 해제로 C: 드라이브 수십 GB 즉각 확보
   - 숨김 전원 플랜 '최고의 성능 (Ultimate Performance)' 잠금 해제
   - 12대 핵심 제어판 애플릿 원클릭 런처 (클래식 제어판, 갓모드, 시스템 속성 등)
4. **Windows 11 필수 맞춤 트윅 탑재**:
   - 작업 표시줄 아이콘 정렬 (왼쪽 정렬 ↔ 가운데 정렬)
   - 시작 메뉴 Bing 웹 검색 결과 차단 (로컬 파일/앱만 즉각 검색)
   - 업데이트 후 강제 자동 재부팅 방지
   - 파일 우클릭 '관리자 소유권 가져오기' 메뉴 등록
5. **컴퓨터 자동 예약 종료 타이머**:
   - 시스템 종료, 다시 시작, 최대 절전 모드 N분 후 예약 및 1클릭 취소
6. **정크 & 레지스트리 청소 및 파일 파쇄기**:
   - 임시 파일, 브라우저 캐시, 크래시 덤프 안전 청소
   - 고아 레지스트리(App Paths, Shared DLLs, MUI Cache) 1클릭 정리
   - 1~7회 덮어쓰기 후 삭제하는 파일 파쇄기 (저장장치/스냅샷/백업에 따라 원본이 남을 수 있음)
7. **기타 유틸리티 계승**:
   - 32/64비트 시작프로그램 자체 격리 안전 관리자 (작업 관리자 비활성화 상태 StartupApproved 반영)
   - 창 투명도(10~100%) 및 Always On Top 고정, 프로세스 일시중지
   - 파일 백업 타임라인 스냅샷 가드
   - 네트워크 트래픽 실시간 모니터링 & hosts 루프백 광고 차단 (원본 백업 후 원자적 교체)
   - 트윅 변경 사항 1클릭 시스템 롤백 복원 센터
8. **관리자 권한 실행 경로**:
   - 기본 실행은 일반 사용자 권한(실행마다 UAC 창이 뜨지 않음)
   - 상단 "관리자 권한 필요" 버튼으로 UAC 승인을 거쳐 관리자 권한으로 재실행 가능
   - 일부 기능(HKLM 레지스트리, hosts 차단, Windows 임시 폴더 정리)은 관리자 권한 필요
