================================================================================
   Click To Tweak Modern 2026 (클릭투트윅 모던 무설치 포터블 에디션)
================================================================================
버전: v1.0.0-PORTABLE (x64 Native)
제작: REA(Reverse Engineer Anything) 역공학 기반 Rust 완전 재창조

■ 1. 프로그램 개요
--------------------------------------------------------------------------------
10년 전 개발이 중단되었던 국민 시스템 유틸리티 '클릭투트윅 (Click To Tweak)'을
현대 Windows 10/11 x64 환경에 맞춰 완전하게 재창조한 무설치(Zero-Install) 포터블 도구입니다.

과거 12개의 분산된 실행 파일(CTTUtil, DesktopFixer, trans, pollock, MemRes 등)과
블루스크린(BSOD)을 유발하던 구형 32비트 커널 드라이버(SMFDDrv, FProtMod)를
완전히 배제하고, 초경량 단일 Rust 바이너리로 통합 구축하였습니다.


■ 2. 폴더 구성 및 실행 방법
--------------------------------------------------------------------------------
- ClickToTweak.exe     : 메인 실행 바이너리 (더블 클릭으로 즉시 실행)
- 실행하기.bat         : 권한 확인 및 자동 실행 런처
- 사용설명서.txt       : 본 안내 문서
- data/                : 설정, 파일 백업 스냅샷, 복원 지점이 보관되는 로컬 데이터 폴더
- tools/               : 구 클릭투트윅 스타일로 각 기능별 빠른 실행 안내 바로가기


■ 3. 주요 기능 안내 (10대 핵심 탭 & 클릭투트윅 전체 유틸리티 현대화 계승)
--------------------------------------------------------------------------------
1. [대시보드 개요]
   - CPU, RAM, 디스크 여유 공간 실시간 모니터링
   - UAC 관리자 권한 상태 자동 감지
   - 원클릭 시스템 메모리 최적화 (Working Set Trimming)

2. [시작프로그램 관리자]
   - 32/64비트 Run, RunOnce, 시작 폴더 전수 탐색
   - 시스템 충돌 없는 자체 격리 키 기반 안전 비활성화 및 1클릭 복원
   - 새 시작프로그램 등록 및 영구 삭제

3. [시스템 & 탐색기 트윅]
   - Windows 11 클래식 우클릭 메뉴 1클릭 복원 ('더 많은 옵션 표시' 생략)
   - 바탕화면 바로가기 화살표 아이콘 제거
   - 알려진 파일 확장자 및 숨김 파일 항상 표시
   - 창 최소화/최대화 애니메이션 끄기로 시스템 반응 속도 극대화
   - 사용자 특수 폴더(다운로드, 문서, 바탕화면) 저장 위치 D 드라이브 등으로 안전 이동
   - 바탕화면 아이콘 좌표 저장 및 1클릭 복구 (DesktopFixer)
   - Windows 탐색기(explorer.exe) 즉시 재시작

4. [제어판 & 시스템 도구 센터 (구 클릭투트윅 제어판 전면 계승)]
   - 바탕화면 시스템 아이콘 제어 (내 PC, 휴지통, 제어판, 사용자 문서, 네트워크 표시/숨김)
   - 마우스 & 키보드 반응 속도 제어판 (키보드 반복 지연 0단계 단축, MenuShowDelay 팝업 지연 단축, 마우스 정밀 가속도 끄기)
   - 전원 & 용량 제어 (최대 절전 모드 hiberfil.sys 해제로 수십 GB 확보, Ultimate Performance 활성화)
   - Windows 11 필수 맞춤 트윅 (작업 표시줄 왼쪽/가운데 정렬, 시작 메뉴 Bing 웹 검색 결과 차단, 업데이트 후 강제 자동 재부팅 방지, 파일 우클릭 관리자 소유권 가져오기)
   - 컴퓨터 자동 예약 종료 타이머 (시스템 종료, 다시 시작, 최대 절전 예약 및 1클릭 취소)
   - Windows 핵심 제어판 애플릿 12종 원클릭 런처 (클래식 제어판, 갓모드, 시스템 속성, 네트워크, 디스크/장치 관리자 등)

5. [정크 & 레지스트리 청소 및 파일 보안 파쇄기 (FileCleaner & RegistryCleaner & Shredder)]
   - [서브탭 1: 정크 & 임시 파일 청소]
     * %TEMP%, C:\Windows\Temp 임시 파일 정리
     * 크래시 덤프 및 오류 보고서 정리
     * 웹 브라우저(Edge, Chrome, Whale) 캐시 안전 청소
   - [서브탭 2: 레지스트리 불필요 항목 청소]
     * 제거된 프로그램의 잔여 실행 경로 (App Paths) 고아 키 탐지 및 정리
     * 누락된 공유 DLL (Shared DLLs) 무효 참조 청소
     * MUI 캐시(MuiCache)의 삭제된 프로그램 명칭 잔여 기록 정리
   - [서브탭 3: DoD 5220.22-M 군사 규격 파일 보안 영구 파쇄기]
     * 복구 프로그램(Recuva, R-Studio 등)으로 절대 복구할 수 없는 파일 영구 삭제
     * 1단계(제로 필) / 3단계(DoD 표준: 0x00 -> 0xFF -> 난수) / 7단계(DoD ECE 최고 보안)

6. [창 & 프로세스 제어 (trans / pollock / CTTUtil 현대화)]
   - 크로스헤어 피커로 마우스 아래의 창 즉시 획득
   - 창 투명도 10% ~ 100% 무단계 조절 (WS_EX_LAYERED)
   - 창 항상 위(TopMost) 고정, 창 제목 변경, 창 숨기기/보이기
   - 프로세스 일시중지(NtSuspendProcess) 및 재개(NtResumeProcess)

7. [파일 보호 & 스냅샷 가드 (FProtect 현대화)]
   - 블루스크린 위험 0%: 위험한 커널 후킹 대신 안전한 로컬 스냅샷 타임라인 엔진 적용
   - 중요 문서/설정 파일 등록 시 언제든 1클릭으로 과거 버전 롤백 복원

8. [네트워크 모니터 & 광고 차단 (TrafficLogger / adfilter 현대화)]
   - 실시간 송수신 대역폭(KB/s, MB/s) 측정
   - 시스템 전역 hosts 루프백(0.0.0.0) 기반 모든 브라우저 및 앱 광고 차단
   - Windows DNS 확인자 캐시 즉시 플러시(초기화)

9. [매크로 플레이어]
   - Windows SendInput API 기반 고속 자동 클릭 및 키보드 연타 매크로
   - 정밀 지연 시간 설정 및 긴급 중지 지원

10. [트윅 복원 센터 (FileBackup 현대화)]
    - 시스템 트윅 적용 전 레지스트리 상태를 JSON 복원 지점으로 자동 백업
    - 설정 오류 발생 시 1클릭으로 이전 상태로 완전 롤백


■ 4. Windows 11 환경 최적화 및 제외된 구시대 레지스트리 항목
--------------------------------------------------------------------------------
- 제외된 레지스트리 항목 (Windows 11에서 역효과 또는 불필요):
  * 구시대 TCP/IP 수신 윈도우 크기(RWIN), MTU 강제 패치: Windows 11의 CTCP 및 자동 튜닝 엔진과 충돌하여 기가비트 속도를 저하시키므로 배제.
  * IE BHO 광고 가로채기 (WebInterception.dll): Internet Explorer 완전 퇴출로 무효.
  * CD/DVD 자동 실행(Autorun) 방지: 현대 PC ODD 드라이브 부재로 실효성 상실.
  * 32비트 커널 필터 드라이버(SMFDDrv, FProtMod): 64비트 DSE(드라이버 서명 강제) 위반 및 BSOD 유발로 현대화 스냅샷 엔진으로 대체.


■ 5. 엔터프라이즈 보안 및 환경 적합성
--------------------------------------------------------------------------------
- V3 백신 / EDR / DLP 오탐 방지:
  * 무서명 커널 드라이버(.sys) 일체 미사용
  * %TEMP% 압축 풀림(Dropper) 방식이 아닌 100% 독립 실행 구조
  * 인라인 무작위 바이너리 스폰 배제
- 포터블(Portable):
  * 레지스트리나 C:\Program Files를 무단 오염시키지 않음
  * USB나 외장 드라이브, 다른 PC로 폴더 전체를 복사해도 즉시 구동 가능
