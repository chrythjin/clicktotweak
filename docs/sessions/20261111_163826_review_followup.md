# 검토 후속 수정

- hosts 파일 수정 시 백업을 먼저 저장하고 임시 파일을 같은 디렉터리에서 교체한다. 교체 실패 시 원본을 직접 덮어쓰지 않는다.
- 레지스트리 백업에 값 형식을 저장하고, 형식 정보가 없는 이전 백업은 잘못된 형식으로 덮어쓰지 않도록 복원을 거부한다.
- 시작 프로그램 상태, 매크로 완료 상태, 창 투명도 및 숨김 상태, 파일 정리 확인, 복원 오류 보고를 보완했다.
- 파일 스냅샷 목록에 대상 경로와 생성 시각을 표시하고 파일만 신규 보호 대상으로 받는다.
- 무거운 시스템 조회와 정리 명령을 비동기 실행 대상으로 지정했다.

검증: 프론트엔드 빌드, Rust 릴리스 빌드와 Rust 단위 테스트 6건 통과. GUI 및 실제 시스템 변경 동작은 검증하지 않았다. Clippy 경고가 남아 있다. 포터블 실행 파일은 교체하지 않았다.
