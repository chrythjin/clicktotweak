## 추가된 기능

- **관리자 권한 실행 경로** (`src-tauri/src/modules/elevation.rs`): 기본 실행은 일반 사용자 권한으로 유지하고,
  상단 "관리자 권한 필요" 버튼을 누를 때만 UAC(`ShellExecuteW`의 `runas`)를 거쳐 재실행한다.
  `get_elevation_status` / `relaunch_as_admin` 명령으로 노출하고 사이드바와 헤더에 상태를 표시한다.
- **백업 가드 폴더 대상 정합화**: 폴더 보호 대상은 목록에서 사라지지 않고 "폴더 미지원"으로 표시되며,
  스냅샷 버튼이 비활성화된다. 원본이 사라진 대상은 "원본 없음"으로 구분한다.
- **CSP 활성화** (`src-tauri/tauri.conf.json`): `csp: null` 을 외부 리소스를 허용하지 않는 정책으로 교체.
- **미사용 권한 제거** (`src-tauri/capabilities/default.json`): 프론트에서 호출하지 않는 `opener:default` 제거.
